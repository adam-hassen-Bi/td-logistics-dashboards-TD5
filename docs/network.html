Decision this supports: which of four discrete network configurations serves the customer base with the least distance — a first, distance-only pass before a full investment study.

Comparing the four options

These configurations are discrete, mutually exclusive choices, not points on a continuum — a line chart would suggest you could interpolate between "3 warehouses" and "4 warehouses". One bar per option, sorted best to worst, answers the question directly. The table shows the same options through the two other dashboards' KPIs.
